About the Project

This system helps recruiters compare resumes with job descriptions. It extracts resume text, identifies common skills and calculates a similarity score using TF-IDF and cosine similarity.

Modules

  • Resume upload and text extraction
  • Job description processing
  • Skill extraction
  • NLP similarity scoring
  • Candidate recommendation
  • Candidate ranking and local database
